# Your Listener Max

An original Windows voice workflow assistant with a floating 3D-style presence, custom calling names, dual activation, dictation cleanup, provider modes, workflows, and an MCP-ready connector hub.

## Run locally

1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm start`.
4. Use `npm run package` on Windows to create the portable executable.

## Safety

Sensitive actions such as calling, messaging, submitting, purchasing, creating, editing, or deleting require an approved connector and explicit confirmation. Never commit API keys, connector credentials, local user photos, or generated build directories.

## Product boundary

This is an original implementation targeting public user-facing voice-assistant outcomes. It does not copy private source code, private models, exact branding, or protected graphics from another product.

## Prompt quality layer

Rough requests are normalized into a structured task with context, quality requirements, clarification questions, warnings, and confirmation rules before unknown actions are executed. The layer does not invent missing recipients, dates, amounts, or permissions.
